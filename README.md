# 🎯 Monitor de Actividad de Protocolos de Red

Este proyecto tiene como objetivo capturar, clasificar y visualizar el uso de protocolos en equipos de red.

## 🧩 Componentes del Proyecto

- Captura de sistema y puertos (PowerShell)
- Cliente en C# que envía datos a la API
- Servicio Windows que corre al inicio
- Ícono en el System Tray sin opción de cierre
- Base de datos MySQL con tablas: Equipo, Fabricante, Protocolo, ProtocoloUsado
- Interfaz web con dashboard y gráficas
- Clasificación de protocolos por seguridad (Verde, Amarillo, Naranja, Rojo)

## 📂 Estructura del Repositorio

# Gestion_Colaborativa
Se simulará el trabajo en equipo dentro de un repositorio compartido. Forma un grupo de máximo cinco integrantes y designa un repositorio principal en GitHub. Cada integrante deberá hacer un fork o recibir acceso al repositorio, clonar el proyecto y contribuir con un archivo propio (por ejemplo, una propuesta, un script o documentación).
